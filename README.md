# PyDM 2.0 — مدير تحميل شبيه بـ IDM

## الحصول على PyDM.exe (اختر طريقة واحدة)
> ملف EXE يُبنى على ويندوز فقط، لذلك لم يُرفق جاهزاً. الطرق التالية تعطيك ملفاً واحداً `PyDM.exe` يعمل على ويندوز 7/8/8.1/10/11 **بدون تثبيت Python على الجهاز الذي يشغّله**.

1. **على جهازك (الأسهل):** ثبّت Python 3.8 من python.org (فعّل tcl/tk و Add to PATH) ← انقر `build_exe.bat` ← تجد `dist\PyDM.exe`.
2. **سحابياً بدون تثبيت أي شيء:** ارفع هذا المجلد إلى مستودع GitHub ← Actions ← Build PyDM.exe ← Run workflow ← نزّل `PyDM.exe` من Artifacts.
3. **مثبّت كامل (اختياري):** بعد بناء الـ EXE افتح `installer.iss` في Inno Setup واضغط Compile ← ينتج `PyDM-Setup.exe` فيه خيار «تشغيل مع ويندوز» واختصار سطح المكتب.

> ملف EXE غير الموقّع قد يظهر له تحذير SmartScreen أو يعتبره بعض مضادات الفيروسات خطراً بالخطأ (ظاهرة معروفة مع PyInstaller). اختر «مزيد من المعلومات ← تشغيل على أي حال»، أو ابنه بنفسك من المصدر كما في الطريقة 1.

**للتشغيل بدون بناء:** ثبّت Python 3.8 وانقر `run.bat`.

## التشغيل مع ويندوز
الإعدادات ← **تشغيل PyDM تلقائياً عند بدء ويندوز**. يبدأ مصغّراً في شريط المهام، ويستأنف التحميلات غير المكتملة، ويُشغّل خادم الإضافة فتعمل المتصفحات فوراً. لا يحتاج صلاحيات مدير (يُسجَّل للمستخدم الحالي)، ولا يسمح بتشغيل نسختين معاً.

## تثبيت إضافة المتصفح
شغّل PyDM أولاً (يجب أن يكون التكامل مفعّلاً في الإعدادات، المنفذ الافتراضي 6800).

*الإضافتان مضمّنتان داخل PyDM.exe: من القائمة مساعدة ← تثبيت إضافة المتصفح ← «استخراج إضافة …» ثم اتبع الخطوات.*

**Chrome / Edge / Brave / Opera**
1. افتح `chrome://extensions` (أو `edge://extensions`).
2. فعّل **وضع المطور**.
3. **Load unpacked / تحميل إضافة غير مفعّلة** ← اختر مجلد `extension_chrome`.

**Firefox**
1. افتح `about:debugging#/runtime/this-firefox`.
2. **Load Temporary Add-on** ← اختر `extension_firefox\manifest.json`.
3. هذه الطريقة مؤقتة (تُحذف عند إغلاق Firefox). للتثبيت الدائم: وقّع الإضافة من addons.mozilla.org (النشر «غير مدرج»)، أو استخدم Firefox ESR/Developer Edition مع `xpinstall.signatures.required=false`.

**ما تفعله الإضافة**
- تعترض التحميلات (حسب النوع/الحجم المحدد في إعداداتها) وترسلها إلى PyDM مع الكوكيز والمرجع، فتعمل المواقع التي تتطلب تسجيل دخول.
- إذا كان PyDM مغلقاً يكمل المتصفح التحميل بنفسه.
- قائمة النقر اليمين على أي رابط/فيديو/صورة: «التحميل باستخدام PyDM».
- أيقونة الإضافة تعرض روابط الفيديو والصوت المرصودة في الصفحة (مثل شريط IDM).

## ويندوز 8.1: ملاحظات
- آخر إصدار من Chrome/Edge يدعم 8.1 هو **109**، وآخر Firefox هو **ESR 115**؛ الإضافة تدعمهما.
- إن ظهر خطأ شهادة SSL (يحدث لأن ويندوز 8.1 القديم قد لا يعرف بعض الشهادات الحديثة): شغّل `pip install certifi` (يستخدمه البرنامج تلقائياً)، أو كحل أخير فعّل «تجاهل أخطاء شهادة SSL» من الإعدادات.

## الأمان
- خادم التكامل يستمع على `127.0.0.1` فقط، ويرفض أي طلب قادم من صفحات الويب العادية (يقبل الإضافات فقط).
- الكوكيز تُرسل فقط إلى موقع الرابط الأصلي، ولا تُرسل عند إعادة التوجيه لموقع آخر، وتُحذف من القائمة المحفوظة عند اكتمال التحميل.

## ما لا يدعمه
- فيديوهات المواقع المقسّمة (HLS/m3u8/DASH مثل يوتيوب) والمحتوى المحمي بـ DRM. لهذه الحالات استخدم أداة `yt-dlp` (يمكن دمجها لاحقاً).
- الملفات التي لا يدعم خادمها التحميل المجزّأ تُحمَّل باتصال واحد وبدون استئناف.
